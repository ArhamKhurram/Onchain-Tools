The **Directory** is your private watchlist of on-chain addresses — whales, KOLs,
or any wallet you want to keep an eye on. (It used to be called "Wallets"; old
`/wallets` links redirect here.)

Unlike [Portfolio](./portfolio/), which tracks *your* wallets and PnL, the
Directory is about watching *other people's* wallets.

## Adding wallets

Use **Add wallet** to open the form. Each wallet can have an emoji, a label, and
a profile note, and is tagged with its chain. The toolbar has a **Search**
(address, label, profile, or emoji) and a **chain filter**.

## The table

| Column | What it shows |
| --- | --- |
| **Wallet** | Emoji + name + profile note |
| **Address** | Copyable, truncated |
| **Chain** | Colored chain tag |
| **Alerts** | Three toggles — **Toast**, **Feed**, **Bubble** — lit when on |
| **Actions** | Edit / Delete |

## Alert types

The three per-wallet alert toggles control how you're notified when that wallet
is active:

- **Toast** — an in-app popup.
- **Feed** — surfaces the activity in your feed.
- **Bubble** — an inline indicator.

Turn on whichever combination fits how closely you're tracking each wallet.
