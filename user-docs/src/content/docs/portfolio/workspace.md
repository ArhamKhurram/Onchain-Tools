The **Workspace** lets you assemble a custom dashboard — mix feeds, radar,
contracts, and FOMO into a multi-column layout that fits how you actually work.

## Building a layout

Enter **Edit** mode from the toolbar, then **Add column** and **Add panel**. You
can have up to **6 panels** across **3 columns**. Drag panel headers to reorder,
drag the splitters to resize. **Save** keeps it; **Cancel**, **Reset**, and
per-panel removal are all there too.

## Widget types

| Widget | Shows |
| --- | --- |
| **Room feed** | A live room, like a Feed pane |
| **Contract feed** | The contract feed |
| **Radar** | The token radar |
| **FOMO live** | The live FOMO trade feed |
| **FOMO leaderboard** | Top traders |
| **Token lookup** | Top FOMO holders for an address you enter |

Your layout is saved to your settings, so it follows you (across devices in
hosted mode). A room panel opens a picker so you can choose which room it shows.
