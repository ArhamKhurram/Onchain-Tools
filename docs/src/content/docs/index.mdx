## What is OCT?

Onchain Tools ingests Discord and Telegram streams in real time, detects and
enriches contract addresses, tracks fomo.family traders, and raises
convergence and missed-runner alerts. It ships three ways: a hosted web
console, a marketing/landing site, and an Electron desktop app.

## The one concept to internalize first

Almost every branch in this codebase keys off **local vs hosted mode**. Local
mode is a single implicit user with JSON-file storage and no auth (the desktop
app). Hosted mode is multi-tenant on Supabase with bearer-token auth (the
Railway + Vercel deployment). Read [Two deployment modes](./architecture/two-modes/)
before touching anything else.
